# AgentsView — русский интерфейс

Просматривайте историю работы ИИ-агентов, находите нужные диалоги и следите за
активностью и расходами. Архив сессий хранится на вашем компьютере. Отправка
данных наружу происходит только при использовании соответствующих функций,
например публикации сессии.

Это форк [kenn-io/agentsview](https://github.com/kenn-io/agentsview) с русской
локализацией. Полная исходная документация сохранена в
[английской README](README.en.md). Проект распространяется по [лицензии MIT](LICENSE).

## Что переведено

- Главная панель аналитики: сводка, активность, проекты, инструменты, навыки,
  качество и результаты сессий.
- Основная навигация, фильтры, выбор периода и строка состояния.
- Выбор языка интерфейса и поиск внутри сессии.
- Названия дней недели, даты и числовые показатели главной панели с учётом
  выбранного языка.

Это частичная локализация. Непереведённые разделы используют английские тексты.
Имена агентов, моделей и проектов, команды, пути, содержимое диалогов и форматы
экспорта сохраняются в исходном виде.

## Как включить русский язык

В сборке из этого форка откройте **Settings → Language → Interface language**
и выберите **Русский**. Выбор сохраняется на этом устройстве. При первом
запуске без сохранённого выбора русский включается автоматически, если это
предпочтительный поддерживаемый язык браузера.

Официальный установщик и официальные выпуски исходного проекта не содержат
изменений этого форка. Для русского интерфейса нужна сборка из этих исходников.
Готовый установщик с переводом пока не опубликован.

## Возможности AgentsView

- Единый локальный архив сессий Claude Code, Codex и других ИИ-агентов.
- Полнотекстовый поиск и переход к нужным сообщениям.
- Поиск по смыслу после настройки индекса эмбеддингов.
- Аналитика активности, использования токенов и стоимости.
- Сравнение агентов, проектов и инструментов.
- Просмотр изменений, качества сессий и повторяющихся затруднений.
- Импорт, экспорт и дополнительные интеграции.

## Запуск исходной программы

Официальный выпуск без перевода можно скачать со страницы
[выпусков исходного проекта](https://github.com/kenn-io/agentsview/releases).
Эти команды относятся к уже установленной программе:

```bash
agentsview serve
```

После запуска веб-интерфейс доступен по адресу
[http://127.0.0.1:8080](http://127.0.0.1:8080).
Для фонового запуска и управления сервером:

```bash
agentsview daemon start
agentsview daemon status
agentsview daemon stop
```

При первом запуске AgentsView обнаруживает сессии поддерживаемых агентов и
сохраняет их в локальном архиве SQLite.

## Разработка и сборка перевода

Веб-интерфейс написан на Svelte 5 и TypeScript. Переводы хранятся в
[`frontend/messages`](frontend/messages), а список языков — в
[`frontend/project.inlang/settings.json`](frontend/project.inlang/settings.json).
Русские сообщения находятся в [`ru.json`](frontend/messages/ru.json) и
[`find/ru.json`](frontend/messages/find/ru.json).

Для работы с интерфейсом установите подходящую версию Node.js из
[`frontend/package.json`](frontend/package.json) и инструменты Vite+.
Команды из каталога `frontend`:

```bash
vp install
npm run i18n:compile
npm run check
npm test -- src/lib/i18n
npm run build
```

Готовые ресурсы интерфейса создаются в `frontend/dist`. Они используются при
сборке сервера и настольного приложения. Инструкции по полной сборке,
необходимым Go, CGO и Rust смотрите в
[исходной README](README.en.md), [Makefile](Makefile) и
[правилах сборки](docs/agents/build.md).

Во всех каталогах переводов должен сохраняться одинаковый набор ключей.
Параметры сообщений и технические идентификаторы менять нельзя. Для русских
счётчиков учитываются формы `one`, `few`, `many` и `other`.
